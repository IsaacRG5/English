# Python Grade Average Calculator

This is a simple Python program that calculates the average of three grades and determines whether the student passes or fails based on the result.

## Concepts Used

This program uses basic Python concepts:

input() → to receive data from the user

int() → to convert text to numbers

Arithmetic operations (+, /)

if / else → conditional logic

print() → display results
